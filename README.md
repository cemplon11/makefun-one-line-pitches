Entry for the [make.fun bounty "A Day of One-Line Pitches"](https://make.fun/bounty/u-ronigrv-a-day-of-one-line-pitches-12cd9bb3):
one sentence, at most 240 characters, that would convince a friend who has
never coded to let an AI agent build their first app idea on make.fun.

## The pitch

> Tell an AI agent on make.fun your app idea in plain words and it will build the app for you, no coding needed, free to try.

## How it works

`main.py` (pure Python stdlib, no dependencies) validates the sentence —
one sentence, 1–240 characters, UTF-8 — and writes it to `/output/entry.txt`.

```sh
python3 main.py
cat /output/entry.txt
```
